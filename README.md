# محاسبة المتجر — نسخة تطويرية 0.2.0

مشروع Android أصلي بلغة Kotlin مع Room/SQLite محلية. لا يطلب التطبيق إذن الإنترنت، وبياناته التشغيلية تحفظ على الجهاز.

## الموجود في هذا الإصدار
- هيكل Android Studio قابل للفتح.
- قاعدة بيانات محلية للأصناف والمخزون والعملاء والموردين والمصروفات وحركات الصندوق.
- جداول المبيعات وبنود الفواتير.
- حفظ سعر الصرف مع الفاتورة كسجل تاريخي.
- عملية حفظ فاتورة وخصم المخزون ضمن معاملة قاعدة بيانات واحدة.
- شاشة أولية لإضافة الأصناف وعرضها.

## ما يزال غير مكتمل
- واجهة POS متكاملة وسلة متعددة الأصناف.
- واجهات العملاء والموردين والمصروفات والصندوق والتقارير.
- وحدات تحويل قابلة للضبط لكل صنف.
- النسخ الاحتياطي والاستعادة والتحقق من سلامة ملف النسخة.
- إدارة مرتجعات البيع والشراء وتسويات المخزون.
- اختبار شامل على أجهزة فعلية، ومعالجة ترحيل قواعد البيانات قبل اعتماد بيانات حقيقية.

## تنبيه مهم
هذه نسخة تطويرية وليست برنامجاً محاسبياً جاهزاً للاعتماد التجاري. لا تدخل بيانات المحل الحقيقية قبل اكتمال النسخ الاحتياطي والترحيل والاختبارات.

## البناء
1. افتح المجلد في Android Studio.
2. استخدم JDK 17.
3. يحتاج جهاز التطوير إلى الإنترنت لتنزيل Gradle ومكتبات Android أول مرة.
4. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

التطبيق نفسه لا يحتاج الإنترنت أثناء التشغيل.
