# حالة تنفيذ Good Girl

هذه حالة تطوير أولية وليست إصداراً جاهزاً للاستخدام التجاري.

## تم إنشاؤه في فرع good-girl-rebuild
- تطبيق Android أصلي باسم Good Girl مع شاشة عربية وتنقل أولي بين الأقسام.
- قاعدة SQLite محلية للمواد والمبيعات وحركات المخزون والفواتير والإعدادات.
- دمج المواد والمخزون: إضافة كمية لمادة موجودة تزيد رصيدها وتستبدل سعر تكلفتها بآخر سعر مدخل.
- البيع يخصم الكمية ضمن معاملة قاعدة بيانات واحدة، ويرفض بيع كمية أكبر من المتوفر.
- تسجيل تكلفة المادة وقت البيع حتى لا تتغير أرباح العمليات السابقة عند تحديث التكلفة.
- سعر صرف يدوي محفوظ محلياً.
- تقارير أولية للمبيعات والأرباح اليومية والأسبوعية والشهرية، مع تحويل مبيعات الدولار إلى ما يعادلها بالليرة باستخدام سعر الصرف المحفوظ لكل عملية.
- إنشاء فاتورة متعددة البنود وتصدير PDF ومشاركتها من الجهاز.

## ما يجب إنجازه قبل اعتبار التطبيق مكتملاً
- استكمال واجهات إدارة الأصناف وتعديلها وحذفها وتسويات الجرد وسجل الحركة.
- مراجعة تصميم الواجهة وتعريب كل تفاصيل الفاتورة وتنسيق العربية واتجاه RTL داخل ملف PDF.
- إضافة قائمة فواتير محفوظة وإعادة فتحها وطباعتها.
- نسخ احتياطي واستعادة للبيانات مع اختبار سلامة النسخ.
- اختبارات آلية للحسابات، اختلاف العملات، المخزون، التواريخ، والفواتير.
- تنفيذ بناء GitHub Actions بنجاح، ثم تثبيت APK وتجربته فعلياً على جهاز Android.

لا تدخل بيانات تجارية حقيقية في هذه النسخة التطويرية قبل إكمال النسخ الاحتياطي والاختبارات.
